# 🛍 نوین‌شاپ (NovinShop) — فروشگاه اینترنتی فارسی

> فروشگاه اینترنتی راست‌چین و ریسپانسیو با **HTML + CSS + JavaScript خالص** — بدون هیچ فریم‌ورک و بیلدتولزی.
> شامل سه بخش: **فروشگاه** (مشتری)، **پنل مدیر** و **پنل مشتری** که با `localStorage` به هم وصل‌اند.

---

## ۱. معرفی پروژه

نوین‌شاپ یک قالب فروشگاهی کامل و آماده اجراست؛ ظاهر آن مدرن (کارت‌های شناور، گرادیان برند،
دارک‌مود) و کد آن تمیز و ماژولار است: **یک هسته مشترک دیتا** (`store.js`) که هر سه صفحه از آن
استفاده می‌کنند، پس هیچ داده‌ای در دو جا تکرار نشده.

---

## ۲. تکنولوژی‌ها و ابزارها

| تکنولوژی | کاربرد |
|---|---|
| HTML5 معنایی | ساختار هر سه صفحه |
| CSS3 خالص (متغیرها، Grid ،Flexbox ،Media Query) | کل استایل و ریسپانسیو، بدون فریم‌ورک |
| JavaScript خالص (Vanilla) | منطق فروشگاه و پنل‌ها، بدون کتابخانه |
| `localStorage` | دیتابیس فرانت: محصولات، سبد، سفارش‌ها، کاربران، نشست |
| فونت وزیرمتن (لوکال، `woff2`) | تایپوگرافی فارسی، بدون وابستگی به اینترنت |
| فاوآیکون SVG دستی | لوگوی تب مرورگر |
| Font Awesome (CDN) | فقط آیکون‌ها |
| عکس‌های لوکال (`assets/images`) | ۲۳ عکس JPEG داخل پروژه، بدون هات‌لینک |

## ۳. ساختار پروژه

```
modern-shop-clean/
├── README.md                  ← همین فایل
├── novinshop-single.html      ← نسخه تک‌فایل مینیمال (دموی سبک، مستقل)
└── src/                       ← نسخه اصلی
    ├── index.html             ← فروشگاه
    ├── admin.html             ← پنل مدیر
    ├── account.html           ← پنل مشتری
    ├── css/
    │   ├── shop.css           ← استایل کامل فروشگاه
    │   ├── admin.css          ← استایل کامل پنل مدیر
    │   ├── base.css           ← استایل مشترک + فونت پنل مشتری
    │   └── panel.css          ← چیدمان سایدباری پنل مشتری
    ├── js/
    │   ├── store.js           ← تنها منبع حقیقت (دیتا + هلپر + ورود/خروج)
    │   ├── shop.js            ← منطق فروشگاه
    │   ├── admin.js           ← منطق پنل مدیر
    │   └── account.js         ← منطق پنل مشتری
    └── assets/
        ├── images/products/   ← عکس واقعی هر محصول (phone-nova ،headphone-pro ،... ۱۲ فایل)
        ├── images/            ← hero ،offer ،bannerها ،mini1
        ├── images/blog/       ← عکس‌های مجله
        ├── images/avatars/    ← عکس نظردهنده‌ها
        ├── images/favicon.svg ← لوگوی تب مرورگر
        └── fonts/             ← فونت وزیرمتن لوکال
```

**قانون تمیزی:** هر صفحه فقط استایل و اسکریپت خودش را لود می‌کند؛
دیتا (محصول/کاربر/سفارش) فقط در `store.js` است.

## ۴. بخش‌ها و امکانات

### فروشگاه (`src/index.html`)
- هدر چسبان، منوی موبایل کشویی، جستجوی زنده، **دارک‌مود** (ذخیره در `novin_theme`)
- هیرو با کارت شناور + شمارنده متحرک آمار، نوار ویژگی‌ها (ارسال/گارانتی/بازگشت/پشتیبانی)
- دسته‌بندی‌ها، پیشنهاد شگفت‌انگیز با **تایمر معکوس** و کد تخفیف
- ۱۲ محصول با **عکس واقعی**، وضعیت موجودی («موجود» / «تنها X عدد»)، فیلتر دسته، مرتب‌سازی و شمارش نتایج
- **سبد خرید کشویی** (تغییر تعداد، حذف، کد تخفیف `NOVIN40` و `NOVIN10`)
- **علاقه‌مندی‌ها**، **مشاهده سریع** محصول، تسویه و ثبت سفارش
- بنرها، نظرات مشتریان، مجله، سوالات آکاردئونی، خبرنامه، فوتر کامل

### پنل مدیر (`src/admin.html`) — ورود: `admin / 1234`
- داشبورد: تعداد محصول/سفارش، درآمد، کالای فروخته‌شده + سفارش‌های اخیر + نمودار پرفروش‌ها
- مدیریت محصولات: افزودن/ویرایش/حذف (بلافاصله در فروشگاه اعمال می‌شود)
- مدیریت سفارش‌ها: تغییر وضعیت (در انتظار/تکمیل/لغو)، حذف، جستجو، ریست دمو

### پنل مشتری (`src/account.html`) — ورود: `user / 1234` (+ ثبت‌نام)
- پیشخوان (تعداد و مجموع خرید)، فقط سفارش‌های خودش، خروج از حساب

## ۵. مدل داده (`localStorage`)

| کلید | محتوا |
|---|---|
| `novin_products` | آرایه ۱۲ محصول: `id, name, cat, catFa, price, old, rating, sales, stock, img, desc` |
| `novin_cart` | `[{id, qty}]` |
| `novin_wish` | آرایه `id` محصولات نشان‌شده |
| `novin_orders` | سفارش: `id, code, username, customer, phone, address, items, count, total, status, date` |
| `novin_users` | کاربران: `username, pass, role(admin/customer), name, phone, address` |
| `novin_session` | نشست فعلی: `{username, role}` |
| `novin_theme` | تم فروشگاه: `light/dark` |

**جریان سفارش:** تسویه در فروشگاه ← ذخیره در `novin_orders` (با `username` کاربر لاگین‌کرده) ←
نمایش در پنل مدیر (همه) و پنل مشتری (فقط مال خودش).

## ۷. اجرا

```bash
cd modern-shop-clean/src
python3 -m http.server 8000
# فروشگاه: http://localhost:8000/index.html
# مدیر:    http://localhost:8000/admin.html      (admin / 1234)
# مشتری:   http://localhost:8000/account.html   (user / 1234)
```

> با `file://` هم باز می‌شود، ولی برای فاوآیکون و فونت بهتر است با سرور لوکال تست شود.

تست سلامت JS:

```bash
node --check src/js/store.js && node --check src/js/shop.js && node --check src/js/admin.js && node --check src/js/account.js && echo OK
```

## ۸. محدودیت‌ها (صادقانه برای ارائه)

- بک‌اند واقعی ندارد؛ پرداخت و پیامک نمایشی است و رمزها ساده در `localStorage` است (فقط دمو).
- آیکون‌ها (Font Awesome) تنها وابستگی CDN است؛ برای آفلاین کامل باید لوکال شود.
- فقط وزن Regular فونت وزیرمتن داخل پروژه است (Bold به‌صورت خودکار ساخته می‌شود).
- عکس محصول جدید از ادمین، از عکس‌های موجود انتخاب می‌شود (آپلود فایل، قدم بعدی است).
